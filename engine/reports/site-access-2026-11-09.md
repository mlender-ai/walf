## 1. 결론

1. **자동으로 실제 매물 URL을 얻을 수 있는 곳은 두 곳이다. 둘 다 직접 확인했다.**
   - **브랜드 공식몰(카페24):** 자체 검색으로 상품 페이지를 찾고, 페이지 안의 옵션별 재고까지 읽힌다.
   - **중고나라:** 자체 검색으로 지금 올라와 있는 매물의 주소·제목·가격·등록 시각이 나온다.
2. **번개장터·솔드아웃·무신사는 이용약관이 자동화 도구의 수집을 명시적으로 금지한다.** robots.txt가 허용해도 자동으로 열지 않는다. KREAM은 robots.txt도 약관도 확인하지 못해 열지 않는다.
3. **후루츠패밀리는 상품 페이지는 열 수 있지만, 자체 검색은 주소로 열 수 없다.** 검색이 페이지 안 스크립트로만 동작한다. 매물을 찾는 일은 외부 검색 결과에 기대야 한다.
4. **TEST B 결과**
   - **알려진 상품 페이지 발견:** 성공. 공식몰 자체 검색에 품번을 넣으면 W-JKT26-055 네이비 페이지가 매번 1개 나온다(약 7초).
   - **구매 가능한 네이비 M 매물:** 0건 (2026-11-09 02:51 기준)
     - 공식몰: 네이비 S·M·L **재고 0**
     - 중고나라: 현재 매물 83개 중 해당 상품 없음
     - 나머지: 약관 때문에 확인하지 않음
5. **공식 검색 API는 6곳 모두 찾지 못했다.** 회사 사이트·약관에서 일반에 공개된 매물 검색 API를 찾지 못했다(파트너 전용 API 여부는 확인 못 함).

## 4. 판정 규칙 변경 (이번에 반영)

- **매물로 볼 수 있는 것:** 실제로 연 상품 페이지, 또는 허용된 자체 검색의 매물 목록뿐이다.
- **매물로 보지 않는 것:** 검색 결과 제목, 후기·첫 화면 링크, 열지 못한 페이지. 이것들은 **"수동 확인 단서"**(`leads`)로 따로 남긴다.
- **열지 않는 판매처:** 약관이 금지한 판매처는 robots.txt와 상관없이 열지 않는다. 이 규칙은 엔진 테스트로 확인한다.
