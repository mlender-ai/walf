## 2. 호출 한 번의 추정 비용(가정)

| 작업 | 가정 사용량 | Opus 5.5 | Sonnet 5.5 |
|---|---|---|---|
| 찾아줘 식별 1회 | 입력 4만 · 출력 4천 토큰 · 웹 검색 6회 | **$0.30** | $0.18 |
| 7일 수배 탐색 하루 1회 | 입력 6만 · 출력 6천 토큰 · 웹 검색 12회 | **$0.48** | $0.30 |

## 3. 시나리오별 월 비용

### 사용 가정
- 사용자 1명이 한 달에 찾아줘 1번. 보완 요청 때문에 식별을 다시 하는 비율 20%(식별 1.2회).
- 찾아줘 결과에서 “7일 동안 매물 찾기”를 고르는 비율 30%(하루 1회 × 7일).
- 기다려줘는 사용자당 3벌(정책 상한). 같은 상품 페이지는 하루 한 번만 읽고 여러 Watch가 함께 써요.
- 고유 상품 페이지 비율(가정): 30벌 → 90%, 300벌 → 70%, 3,000벌 → 50%(인기 상품이 겹침).
- 상품 페이지 크기 219KB(2026-11-13 배드블러드 상품 페이지 실측).

### AI(찾아줘) — 유일한 사용량 비례 비용

|---|---|---|---|---|
| 10명 · 30 Watch | 12회 · $3.60 | 21회 · $10.08 | **$13.68** | $8.46 |
| 100명 · 300 Watch | 120회 · $36.00 | 210회 · $100.80 | **$136.80** | $84.60 |

- 7일 탐색이 70% 이상을 차지해요. 같은 날 같은 조건 검색은 재사용해서(`aijobs.ts` `searchKey`) 인기 상품이 겹치면 줄어들지만, 겹침 비율은 가정하지 않았어요.

## 4. 앞으로 생길 비용(아직 없음)

- **중고 매물 동일성 판단**: 중고 플랫폼이 연결되면 새 매물이 같은 상품인지 AI로 볼 수 있어요. Haiku 5.5로 매물 하나 입력 3천·출력 300 토큰이면 약 $0.00045. 고유 상품 1,500개 × 새 매물 하루 5건 × 30일 = 22.5만 건이면 약 $101/월. 브랜드·모델 단어로 먼저 거르고(실험 브랜치 규칙) 10%만 AI로 보내면 약 $10/월. 지금은 중고 플랫폼이 `PENDING_INTEGRATION`이라 0이에요.
- 추가 검색 API(Brave $5/1,000회 등)는 쓰기로 정할 때만.
