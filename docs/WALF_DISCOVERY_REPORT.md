## 0. 핵심 질문에 대한 지금의 답

> "사용자가 다른 플랫폼에서 찾지 못했던 바로 그 옷을, 왈프가 더 정확하고 효율적으로 찾아줄 수 있는가?"

**아직 증명하지 못했다.** 준비된 것과 막힌 것을 나누면 다음과 같다.

| 준비됨 (근거 있음) | 막힘 (병목) |
|---|---|
| **잘못 확정하지 않는 판정:** 품번 정확 일치 + 브랜드·색상 충돌 없음일 때만 확정한다. 연구 R2에서 이 규칙의 잘못된 확정(MATCH)은 세 데이터셋 모두 0건이었고, 제품 규칙은 회귀 테스트로 고정돼 있다 | **실제 판매처:** 적법하게 자동으로 찾는 곳이 BADBLOOD 공식몰 1곳뿐이다. 네이버 쇼핑 API는 종료됐고, 한·일 판매처 13곳 중 공식 검색 API를 공개한 곳은 없다 |
| **조건 검증과 알림:** 색상·사이즈 재고·상태·배송비 포함 가격·통화가 모두 확인돼야 알린다. 실패하거나 확인하지 못하면 알리지 않는다. 사용자별 조건도 섞지 않는다. 지시서 §9 QA 10개 중 9개 충족 | **사진 식별 정확도:** 이미지 검색은 의류 사진 1장 기준 1위 정답률이 52~57%(착용·카탈로그)다. 정확한 상품을 이미지만으로 찾는 수준은 아니고, 제품에는 아직 연결 전이다 |
| **결과 UX:** 정확히 찾음 / 유력 후보 / 못 찾음을 나누고, 만들어 낸 브랜드·모델을 보여 주지 않는다. 계속 찾기와 대체 추천을 구분했다(시뮬레이터에서 끝까지 확인) | **실험 A(정답 20개):** 권리가 확인된 한·일 브랜드 의류 사진이 없어 측정하지 못했다(사용자 결정 대기) |
| **비용:** 로컬 이미지 모델 경로라면 1,000명 기준 월 약 $25(가정)이고, 서버 한 대(4GB)에 올릴 수 있다(R2 실측) | **AI 식별 실측 0건:** Claude 식별은 키가 없어 한 번도 실데이터로 돌지 않았다 |

### 2-2. 제품 규칙·흐름 (자동 테스트)

- `npm run verify`(2026-11-20): 단위 144개, E2E 20·19·21단계, 비용 계산이 모두 통과했다. 모두 모의 AI·모의 판매처 기준이다.
- 지시서 §9 QA 기준표: `docs/WALF_DISCOVERY_GATE34.md` §2
- 실험 B(기다려줘)를 테스트 데이터로 검증한 시나리오:
  - **기존 매물 가격 하락:** 목표가 이하일 때 한 번만 알린다(`v2-watch`).
  - **새 사이즈 매물:** 원하는 사이즈 재고가 확인될 때만 알린다(`v21-discovery`, `v2-watch` sold-out→in-stock).
  - **같은 디자인·다른 모델:** 품번이 다르면 '다른 상품'이라 알리지 않는다. 상품명만 같으면 '같은 옷일 수 있음'으로 따로 표시한다(`v21-review`).
  - **판매 종료(품절):** 알리지 않는다.
  - **판매 예정 상품의 판매 개시:** 시작 알림만 보내고 재고 알림은 따로 간다(`discovery-gate34`).
  - **실제 판매처 데이터로는 검증하지 않았다.**

## 3. 비용

- 유료 API 호출은 0건이다.
- 공식몰 실측(2026-11-19): 자체 검색 588 ms(18건), 상품 페이지 875 ms

## 4. 이번 작업에서 하지 않은 것

- **제품에 이미지 모델(MODA) 연결(Gate 2 통합):** 계약안은 walf-intelligence `docs/WALF_INTEGRATION_CONTRACT.md` §11에 있다(이미지·VLM은 확정 근거로 쓰지 않고 후보·반대 근거로만). 제품 코드는 아직 바꾸지 않았다.
- **다국어 검색어 발견률 측정:** 일본 판매처를 적법하게 검색할 경로가 없다.
- **Shopify Global Catalog·eBay·Yahoo 연결:** 사용자 결정·신청 전이다.
- **환율 자동 수집과 어드민 환율 입력 화면:** 기록 함수만 있다.
- **초기 수익화 검증(§7):** 지불 의향 설문과 결제 행동 기록은 실제 사용자가 생긴 뒤의 일이라 만들지 않았다.
- **실기기 푸시, Android:** 확인하지 않았다.

## 6. 다음 우선순위 제안

1. **실제 판매처 넓히기.** 가장 큰 병목이다. 순서는 이렇게 제안한다.
   - Shopify Global Catalog로 찾아줘 즉시 검색을 붙인다.
   - 운영자가 약관을 확인해 허용 목록(`seed/page-hosts.json`)과 공식몰 목록을 늘린다.
   - 제휴(구구스·메르카리 등)를 진행한다.
2. **MODA를 운영자 검수 보조로 연결.** 확정에는 쓰지 않고, 후보 정렬과 '다를 수 있음' 경고에만 쓴다. 대체 추천(`SimilarProductProvider`) 후보 공급에도 쓴다. 서버 4GB 한 대에 올릴 수 있다.
3. **실험 A를 사용자 사진으로 실행.** 식별 → 매물 발견 → 조건 일치를 끝까지 잰다.
4. **환율 어드민 입력, 판매처 카드의 후보 기준 표시.**
