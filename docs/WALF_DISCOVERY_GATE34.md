## 2. 지시서 §9 QA 기준

| 기준 | 상태 | 근거(테스트) |
|---|---|---|
| 이미지가 비슷한 다른 모델을 같은 상품으로 확정하지 않는가 | 충족(규칙). 사진 비교는 제품에 없음 | 품번 정확 일치·브랜드 충돌 규칙(`v21-review`) · 사진 비교는 Intelligence 연구 중 |
| 시즌·브랜드 근거가 없으면 미확인 처리하는가 | 부분 | 브랜드를 확인하지 못하면 '브랜드 확인 못 함'으로 표시. 시즌은 같은 상품 판정에 쓰지 않음(근거 없는 시즌을 확정하지 않음) |
| 실제 사이즈를 이미지에서 추측하지 않는가 | 충족 | 사이즈는 사용자 입력과 판매 페이지 옵션에서만 읽음 |
| 품절 매물을 구매 가능하다고 표시하지 않는가 | 충족 | 품절·재고 미확인은 알림 없음. 수량 비공개 재고 해석 테스트. "구매 가능" 문구 없음(E2E) |
| 엔화·원화 비교 시 환율·기준 시각이 명확한가 | 충족 | `[통화]`·`[환율]` 테스트: 환율 없으면 비교 안 함, 3일 넘은 환율 안 씀, 알림 문구에 환율·기준 시각·출처 |
| 중고·미사용 신품 구분이 정확한가 | 충족(표기 기준) | `[상품 상태]` 테스트. 표기가 없는 중고 플랫폼 매물은 미확인 |
| 다른 사용자의 감시 조건을 섞지 않는가 | 충족 | `[QA] 서로 다른 사용자` 테스트: 같은 페이지는 한 번만 읽고, 사이즈·목표가는 사용자마다 따로 판정 |
| 워커가 실패했을 때 허위 성공 알림을 보내지 않는가 | 충족 | `[QA] 조회가 실패하면` 테스트 |
| 사용 권한이 없는 판매처를 자동 수집하지 않는가 | 충족 | `[허용 목록]` 테스트 3개 |
| 실제 데이터와 데모 데이터를 구분하는가 | 충족 | `is_mock` · 결과 화면 데이터 종류 안내(PR #2) |

## 4. 하지 않은 것·남은 위험

- **다국어 검색어(한·영·일)는 만들지 않았다.** 일본 판매처를 적법하게 검색할 경로가 아직 없어 검색어 조합별 발견률을 잴 수 없다. Shopify Global Catalog나 Yahoo 연결 뒤에 측정한다.
- **Shopify Global Catalog는 연결하지 않았다.** 가입만으로 쓸 수 있지만 요금·한도와 기다려줘 주기 재조회 허용 여부가 미확인이다. 연결하려면 사용자 결정이 필요하다.
- **환율 자동 수집은 연결하지 않았다.** 한국수출입은행 API는 인증키가 필요하다. 지금은 운영자가 출처와 기준 시각을 넣어 기록하는 함수(`recordFx`)만 있고, 어드민 입력 화면은 다음 단계다.
- **판매 예정 일정:** 사용자 앱에서는 기다려줘 상세에 한 줄로만 보인다. 화면 다듬기는 Gate 5(UX)에서 한다.
- **상품 상태 판정:** 상품명 표기에 기댄다. 표기가 없거나 반대로 적힌 매물은 틀릴 수 있다. 다만 '미확인'이면 알림을 보내지 않는 쪽으로 기운다.
- **허용 목록은 지금 BADBLOOD 공식몰 1곳이다.** 운영자가 판매처 약관을 확인해 `seed/page-hosts.json`에 넣어야 늘어난다. 사용자 링크 대부분은 왈프 팀 확인으로 간다.
