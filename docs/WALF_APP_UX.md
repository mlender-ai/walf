# WALF 앱 · 출시 수준 UX 정리 (2026-11-20)

시뮬레이터에서 직접 써 본 피드백을 반영했다. 피드백은 네 가지였다. 하단 탭이 기다려줘 버튼을 가린다. MY에 테스트용 항목이 보인다. 기다려줘 상세가 너무 길다. 전체적으로 출시 제품처럼 보이지 않는다.

## 1. 문제와 결정

| 화면 | 문제 | 결정 | 이유 |
|---|---|---|---|
| 홈(첫 화면) | 떠 있는 탭이 기다려줘 버튼과 '내가 찾는 옷' 줄을 가렸다. 베타 안내 한 줄이 버튼을 아래로 밀었다 | 화면 높이에 맞춰 강아지 그림만 비율대로 줄여서, 두 버튼과 진행 중인 옷 줄이 첫 화면에 다 보이게 했다. 베타 문구는 MY 맨 아래로 옮겼다 | 첫 화면의 일은 '찾아줘·기다려줘 중 하나를 누르기'다. 그림은 줄여도 되지만 버튼은 가리면 안 된다 |
| 홈·추적함 | 탭에 들어올 때마다 위에 큰 로딩 공백이 생겼다. 20초마다 하는 자동 갱신이 당겨서 새로고침 스피너를 켰기 때문이다 | 스피너는 사용자가 직접 당길 때만 보인다(`usePull`). 자동 갱신은 화면을 밀지 않고 조용히 한다 | 사용자가 하지 않은 동작에 화면이 반응하면 고장처럼 보인다 |
| 추적함 | 목록 중간에 큰 찾아줘·기다려줘 버튼 두 개가 끼어 있었다 | 오른쪽 위 `+` 하나로 바꿨다. 누르면 iOS 액션 시트로 찾아줘·기다려줘를 고른다. 목록이 비었을 때만 큰 버튼을 보인다 | 목록 화면은 목록이 주인공이다. 새로 맡기기는 iOS에서 익숙한 자리(오른쪽 위)에 둔다 |
| MY | 서버 주소 입력, 기기 ID, 이전 기록 이어받기 코드 칸이 항상 보였다 | iOS 설정처럼 묶음 목록(알림 · 이용 안내 · 앱 정보 · 데이터)으로 바꿨다. **개발자 설정은 '버전' 줄을 길게 눌러야 열린다.** 연결 오류 화면의 '서버 주소 확인'도 이곳으로 연다. **이전 기록 이어받기는 정말 잠긴 기기에서만** 맨 위 안내로 보인다. 이용 안내는 별도 화면(`/guide`)으로 옮기고, 문구는 그대로 두고 주제별로만 묶었다 | 일반 사용자는 테스트 항목을 볼 일이 없다. 알림이 꺼져 있으면 '켜기' 버튼이, 거부했으면 '설정 열기' 버튼이 그 줄에 붙는다 |
| 기다려줘 상세 | 한 화면에 상태, 가격, 가격 기록, 새 판매처, 비슷한 옷, 조건, 기록, 멈춤·끝내기가 모두 이어져 스크롤이 길었다 | **위는 요약**(어떤 옷 · 지금 상태 · 마지막 가격과 확인 일정)으로 두고, **아래는 탭**(가격 · 다른 판매처 · 비슷한 옷 · 기록)으로 나눴다. 탭 막대는 스크롤해도 위에 붙는다. 탭을 바꿔도 막대 위치는 그대로다. 조건 바꾸기, 판매처에서 보기, 잠시 멈추기·다시 지켜보기, 끝내기는 오른쪽 위 `⋯` 메뉴로 옮겼다(끝내기는 빨간 글씨와 확인 창). 조건 바꾸기는 iOS 시트로 연다. 멈춘 상태에서는 '다시 지켜보기' 버튼을 요약에 바로 보인다 | 자주 보는 것(지금 가격·상태)은 위에, 가끔 보는 것은 탭에, 관리 동작은 메뉴에 둔다 |
| 알림 → 기다려줘 | 새 판매처·비슷한 옷 알림을 눌러도 상세 맨 위로만 갔다 | 알림 링크에 `?tab=offers` / `?tab=similar`를 붙여 해당 탭을 바로 연다. 예전 링크(`walf://watch/1`)도 그대로 열린다 | 알림이 말한 내용을 눌렀을 때 바로 보여야 한다 |
| 찾아줘 → 기다려줘 | 같은 옷을 찾은 뒤 기다려줘로 넘어가면 사이즈와 판매 링크를 다시 입력해야 했다 | 맡길 때 적은 사이즈·색상을 넘긴다. 왈프 팀이 **같은 상품으로 확인한 판매 페이지**가 있으면 링크도 미리 넣고, 그렇다는 안내를 붙인다. 근거 페이지나 확정 전 후보의 판매처는 넣지 않는다 | 이미 아는 것을 다시 묻지 않는다. 다만 확인되지 않은 링크로 가격을 지켜보면 안 된다 |
| 없는 주소 | 알 수 없는 링크로 들어오면 개발용 'Unmatched Route' 화면이 떴다 | '찾을 수 없는 화면이에요' 화면과 홈으로 버튼을 넣었다(`+not-found`) | 출시 앱에 개발 화면이 보이면 안 된다 |

서버 쪽도 함께 바꿨다.
- 기다려줘 알림 문구의 '구매 가능 알림'을 '가격 알림'으로 바꿨다. 사용자에게 '구매 가능'이라고 말하지 않는다.
- 운영자가 확인한 배송비를 기다려줘 가격 카드에 반영한다(`watchView`가 매물의 배송비를 씀).

## 2. 확인

- 시뮬레이터(iPhone 17 Pro, 데모 서버)에서 다음 화면을 직접 확인했다.
  - 홈 첫 화면에 두 버튼과 진행 중 줄이 다 보인다.
  - 추적함에 로딩 공백이 없고, `+` 액션 시트가 뜬다.
  - MY 묶음 목록이 보이고, 버전 길게 누르기로 개발자 설정이 열리고 닫힌다. 이용 안내 화면도 확인했다.
  - 기다려줘 상세: 탭 고정, 탭 전환, `⋯` 메뉴, 조건 바꾸기 시트, `?tab=offers` 링크가 모두 동작한다.
  - 없는 주소 화면이 뜬다.
  - 찾아줘 → 기다려줘에서 확인된 판매 링크와 사이즈 M이 미리 들어간다.
- 앱 `tsc --noEmit` 통과. `expo lint`는 이번에 바꾼 파일에서 문제 0건이다. 남은 13건은 기존 파일(`candidate/[id]`, `request/departure`, `lib/store`, `lib/push`)에 있다.
- 서버 `npm run verify`: 단위 145개, E2E 3개 모두 통과.

## 3. 하지 않은 것

- 실기기와 Android에서는 확인하지 않았다. Android의 `⋯` 메뉴와 `+`는 액션 시트 대신 기본 알림 창으로 뜬다.
- 기존 파일의 린트 경고 13건은 그대로 두었다. 이번 범위 밖이다.
- 다크 모드는 지원하지 않는다. 앱 전체가 라이트 고정이다.
