## 3. 두 가지 식별 구조

- **A. 지금 코드의 설계:** 사진·이름을 Claude(Sonnet)에게 보내고 웹 검색으로 식별한다(`server/src/ai.ts`). 요청마다 유료 호출이 1번 들어간다.
- **B. 제안:** 서버 CPU에서 이미지 임베딩(MODA)으로 후보를 먼저 좁히고, 품번·브랜드 규칙으로 판정한다.
  - 확인이 필요한 30%만 소형 멀티모달 모델(유료 API)로 다시 확인하는 것은 선택 사항이다.
  - 판매처 검색은 외부 비용이 없는 공식몰 자체 검색을 쓴다. 네이버 쇼핑 API는 종료돼 이제 쓸 수 없다.
- **로컬 VLM 재검증과 OCR은 B의 기본 경로에서 뺐다.** 근거는 아래 §3-1의 R2 실측이다.
  - 로컬 VLM 재검증은 판매 의류에서 효과가 없었고, CPU에서 1회 약 30초가 걸린다.
  - OCR은 판매 사진에서 근거가 나오는 비율이 2~3%다.

**품질은 아직 비교하지 않았다.** A는 실데이터 정확도가 0건 측정 상태다. B는 Lab에서 신발·가방·모자로만 측정했다. 그래서 아래 표는 비용만 비교한다. B가 A만큼 정확하다는 뜻이 아니다(Gate 1·2에서 같은 평가셋으로 비교한다).

## 3-1. 서버 기준 실측 (연구 세션 R2, 2026-11-20)

측정 조건:
- Apple M5에서 MPS를 끄고 CPU 스레드를 제한했다.
- 사진 30장, 워밍업 3장 제외, 설정마다 새 프로세스로 쟀다.
- M5 코어는 클라우드 vCPU보다 빠르다. 그래서 **지연은 서버에서의 하한**으로 본다.
- 원문은 walf-intelligence 로컬 브랜치 `claude/intelligence-r2`(fe52072)의 `docs/R2_IDENTIFICATION_REPORT.md` §6-2, 수치 파일은 `r1_identify/results/r2/server_bench.json`이다.

**4GB 서버 한 대에 올리는 것**은 MODA(약 1.95 GB)와 제품 서버(약 0.12 GB 이상)다.
- 운영체제와 여유분을 더해 약 2.6~2.8 GB로 추산한다(추산값이며 측정하지 않았다).
- OCR까지 올리면 약 4.3 GB라 넘친다.
- 8GB 서버 단가는 이번에 공식 가격으로 확인하지 않았다(미확인).

**월 계산량(가정):**
- 10,000명 × 사진 2장 × 147 ms(p95) = 월 약 49분 CPU다. 요청 처리 비용은 서버 고정비 안에 들어간다.
- 판매처 카탈로그를 미리 임베딩하는 시간은 카탈로그 크기에 비례한다(예: 사진 10만 장 × 87 ms ≈ 2.4시간, 가정).

### 중복 제거율이 바꾸는 것
- 감시 페이지 조회와 감시 탐색 횟수가 그대로 0% → 30% → 60% 줄어든다.
- 돈이 달라지는 건 **유료 검색을 쓸 때뿐**이다. 1,000명 기준 Claude 웹 검색이면 $147 → $91, 10,000명이면 $1,474 → $905다.
- 공식몰 자체 검색만 쓰면 비용 차이는 없다. 대신 **판매처에 보내는 요청 수**가 줄어든다. 10,000명 기준 하루 3,000회 → 1,200회다.

### 실패·재시도
- 실패율 5%와 2회 재시도를 넣으면 호출이 5.25% 는다.
- 과금 방식에 따라 차이가 난다.
  - SerpApi는 실패를 과금하지 않는다.
  - Claude·Gemini는 응답을 받은 뒤 정리에 실패해 다시 부르면 다시 과금된다.
  - 공식몰 페이지 조회는 외부 비용이 없고, 판매처 부담만 는다.

## 5. 규모별 병목 (비용보다 먼저 막히는 것)

1. **실제 판매처 수.** 지금 자동으로 찾는 실제 판매처는 1곳이다. 비용과 상관없이 매물 발견률을 막는 가장 큰 요인이다(판매처 접근 매트릭스 참고).
2. **운영자 검수 시간.**
   - 재검증 대상을 모두 사람이 확인하면 10,000명에서 월 150시간(약 0.9명분)이 필요하다.
   - 자동 판정 정확도가 입증되기 전까지는 이 시간이 가장 비싼 항목이 될 수 있다.
3. **무료 공식 검색 경로가 없다.** 네이버 쇼핑 API는 종료됐고, Google Custom Search는 신규 가입이 안 된다. 그래서 검색을 늘리려면 유료(Claude 웹 검색) 또는 제휴(eBay·Yahoo 등)가 필요하다. SerpApi는 원 출처 허가가 아니라 채택하지 않는다(가격만 참고: 월 30,000회를 넘으면 맞춤 견적).
4. **판매처당 요청량.**
   - 감시가 한 판매처에 몰리면 10,000명 기준 하루 최대 3,000회(1초 간격이면 약 50분)가 한 사이트에 간다.
   - 판매처별 허용 빈도를 지키려면 중복 제거와 변경 감지가 비용보다 먼저 필요하다.
5. **무료 AI 등급의 데이터 정책.** Gemini 무료 등급은 입력 데이터를 제품 개선에 쓴다고 명시한다. 사용자 사진에는 무료 등급을 쓰지 않는다.
