# WALF Discovery Upgrade · Gate 0 진단

기준일 2026-11-19 · 브랜치 `feat/walf-discovery-upgrade`(PR #2의 `feat/walf-v2.1` 164a2d0에서 시작) · 지시서 "WALF Intelligence & Discovery Upgrade" §1

이 문서는 지시서가 가정한 구조가 실제로 있는지 코드·테스트·실측으로 확인한 결과다. 판정은 다섯 가지로 쓴다.

- **구현·검증 완료**: 코드가 있고 자동 테스트나 실측으로 동작을 확인했다.
- **구현됐으나 미검증**: 코드는 있지만 실제 데이터·키로 돌려 본 적이 없다.
- **부분 구현**: 일부 경로만 있다.
- **미구현**
- **접근 권한 미확보**

## 1. 한 줄 요약

왈프는 **"같은 상품인지 확인하는 규칙"과 "감시·알림 흐름"은 단단하지만, 사진을 이해하는 AI와 실제 매물을 찾을 판매처는 거의 연결되지 않은 상태**다.

- 오늘 실제로 매물을 자동으로 찾는 곳은 BADBLOOD 국내 공식몰 1곳뿐이다.
- 사진 식별 AI(Claude)는 코드만 있고 키가 없어 한 번도 실데이터로 돌지 않았다.
- 이미지 임베딩은 제품에 없고 Intelligence Lab에서만 실측했다.
- 기대했던 무료 공식 검색 경로가 막혔다.
  - 네이버 쇼핑 검색 API는 2026-07-31에 종료됐다(공지 원문 확인).
  - Google Custom Search는 신규 가입이 안 된다.
  - 조사한 한·일 판매처 13곳 중 공식 상품 검색 API를 공개한 곳은 없다(`docs/WALF_SOURCE_ACCESS_MATRIX.md`).
- **준수 결함 1건:** 사용자가 준 상품 링크를 매일 자동 확인하는 기능이 "막을 곳만 적는" 방식이다. 그래서 약관상 허가가 필요한 메르카리·eBay·ZOZO 등의 링크도 robots.txt만 허용하면 자동으로 열린다(아래 데이터 권한 줄).

## 5. Claude / Codex 역할의 실제 상태

- 지시서 §10은 "Codex = Intelligence R&D"로 나눴지만, 바로 앞 지시서에 따라 **Intelligence는 Claude 연구 세션이 Lab 저장소에서 맡고 있다.**
- Codex 흔적은 Lab 저장소의 `codex/*` 브랜치(11/13·11/17 작업)와 원격 main 커밋 1개(5d7091e, 11/19 18:34)다.
- 지금 Codex가 진행 중인 작업은 확인되지 않았다.
- 겹치지 않게 이렇게 나눈다:
  - 연구 세션은 `walf-intelligence` 저장소만, 제품 작업은 `walf` 저장소만 고친다.
  - 접점은 `WALF_INTEGRATION_CONTRACT.md`(Lab), `SimilarProductProvider`(`curation.ts:13`), 식별 계약(`AiProvider`, `ai.ts:21`)이다.

## 6. 재사용·보완 결정

**그대로 쓴다**
- 동일성 규칙(`sameproduct.ts`)
- 알림 조건(`fitOf`)과 "같은 옷일 수 있음" 분리
- 운영자 검수 흐름
- 테스트·실제 구분(`is_mock`)
- 소스 인터페이스와 상태값
- 같은 URL 조회 공유
- 비용 상한

**고친다 (Gate 3·4)**
1. 카페24 재고 해석(수량 미공개 → 미확인, 교차 확인). 실측 결함이다.
2. 링크 자동 확인의 판매처 판단. 막을 곳만 적는 방식에서 허용 목록 방식으로 바꾸는 것을 제안한다(사용자 결정). 바꾸기 전이라도 매트릭스에서 "제휴·허가 필요"나 "자동 접근 불가"로 판정된 곳은 막는다.
3. 상품 상태 5분류, 판매 예정 상태, 근거 형식 통일. 호환 마이그레이션으로 한다.
4. 통화·환율. 일본 판매처보다 먼저 한다.
5. Source Registry: `sources.ts`의 판단 표를 판매처 접근 매트릭스의 항목(공식 API·제휴·약관·robots·요청 제한·한국 배송·판정·확인일)으로 넓힌다.

**새로 만들지 않는다**
- 별도 추천 엔진
- 새 DB
- 새 앱 화면 체계

Intelligence 결과는 기존 계약 자리에 꽂는다.

## 9. 이번 Gate 0에서 같이 고친 것

- **네이버 쇼핑 검색 API를 종료 상태로 바꿨다.** `searchsources.ts`의 `naverSource`가 키 없이도 늘 `UNSUPPORTED`를 돌려주게 했고, 종료된 API의 응답 해석 코드는 지웠다.
- **사용자 화면 문구를 고쳤다.**
  - 판매처 안내에서 "네이버 쇼핑은 연결을 준비하고 있어요"를 뺐다.
  - 기다려줘 판매처 목록에는 "서비스가 종료돼 찾을 수 없어요"로 보인다(`discovery.ts` `noteOf`).
- **서버 로그와 체크리스트를 고쳤다.** 시작 로그는 "네이버 쇼핑 API 종료(2026-07-31)"로 바꿨고, `WEEKEND_SETUP_CHECKLIST.md` 5-1과 9절도 고쳤다.
- **테스트를 바꿨다.** 종료된 API의 응답을 해석하는 테스트 1개를 지웠고, 상태·문구 기대값 4곳을 바꿨다.
